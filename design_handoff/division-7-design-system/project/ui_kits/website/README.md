# Division 7 — Website UI Kit

## Overview
A single-page band website prototype covering the core screens a visitor would encounter:

1. **Hero** — Full-bleed concert photo, band name, upcoming show CTA
2. **Shows** — Upcoming tour dates list with ticket links
3. **Music** — Discography / latest release section
4. **About** — Band bio, minimal text
5. **Footer** — Links, socials, copyright

## Design Notes
- Dark-first: `#0a0a0a` base, off-white text
- Gellix Extra Bold Italic for all display headings
- DM Sans for body/nav/labels (Gellix Regular substitute)
- Red (`#e8190e`) used only for accent: sold-out tags, active states, hover color
- Zero border-radius everywhere
- No shadows
- Full-bleed photography always B&W with optional overlay
- Navigation is fixed to top, transparent on hero, solid black on scroll

## Files
- `index.html` — Interactive prototype (click-through screens)

## Fonts
All weights use real Gellix files from `fonts/`: Regular (400), Bold Italic (700), Extra Bold Italic (800).
